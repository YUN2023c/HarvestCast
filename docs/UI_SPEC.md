# UI 设计规范与验收清单

设计体系：**iOS 26 Liquid Glass + 低饱和墨绿**，浅色单模式，把底部 Dock 改为**固定侧边导航**。
内容可读性优先，玻璃只做氛围。

## 1. Token（原样定义，禁止改写数值）

```css
:root{
  --bg:#EDF2EE; --ink:#000000;
  --ink-2:rgba(60,60,67,.60); --ink-3:rgba(60,60,67,.42);
  --card:#FFFFFF; --card-2:#F2F2F7;
  --line:rgba(60,60,67,.29); --line-2:rgba(60,60,67,.20);
  --fill-1:rgba(120,120,128,.20); --fill-2:rgba(120,120,128,.16);
  --fill-3:rgba(118,118,128,.12); --fill-4:rgba(116,116,128,.08);
  --brand:#276B56; --brand-accent:#4E9C80; --brand-soft:rgba(39,107,86,.14);
  --hairline:.5px;
  --r-card:24px; --r-sheet:30px; --r-el:14px;
}
```

语义色只保留三种点缀：红 `#FF3B30`、橙 `#FF9500`、黄 `#FFCC00`。不做深色模式。

## 3. 背景氛围

`body::before` 铺 4 个低饱和主色系径向光斑，`filter: blur(10px) saturate(115%)`，上下用 `mask-image` 羽化 7%，保证与底色无缝衔接。只做氛围，不叠加在内容之上。

## 4. 侧边导航（重点改造）

### PC ≥ 820px

| 项 | 规格 |
|---|---|
| 定位 | `fixed`，`top:20px; left:16px; bottom:20px` |
| 宽度 | 240px |
| 圆角 | 30px |
| 玻璃 | `backdrop-filter: blur(24px) saturate(180%)`，底色 `rgba(249,249,251,.78)` |
| 阴影 | `0 18px 44px rgba(28,46,38,.16)` + 内高光描边 |
| 布局 | 垂直菜单，图标 19px 单色描边 |

选中态 **lens**：垂直滑块，白色 `rgba(255,255,255,.92)`，上下各内缩 4px，柔和阴影，切换 `0.28s cubic-bezier(.32,.72,0,1)`。

图标：未选中 `--ink-3`，选中 `--brand`，`stroke-width` 1.9 → 2.1。
标签：13px。按压：`scale(.96)` + 透明度，回弹 `cubic-bezier(.34,1.56,.64,1)`。
红点徽标：7px 圆点 + 2px 白描边，绝对定位右上。

### 移动 < 820px

侧栏收起为左上浮动触发按钮（44×44，圆角 16，玻璃）；点击从左弹簧滑出抽屉（`translateX`，`.42s cubic-bezier(.22,1.2,.36,1)`）；遮罩 `rgba(16,28,22,.28)`；主内容 `scale(.985)` + `brightness(.96)`。

### 主内容

```css
.main{ margin-left: calc(240px + 24px); }   /* 不设 max-width，内容铺满剩余宽度 */
@media (max-width:819px){ .main{ margin-left:0; padding:66px 14px 48px } }
```

## 5. 玻璃组件

| 属性 | 值 |
|---|---|
| 底色 | `rgba(255,255,255,.58)` |
| 模糊 | `blur(24px) saturate(180%)` |
| 阴影 | `0 18px 44px rgba(28,46,38,.14)` + `0 2px 6px` |
| 内高光 | `inset 0 1px 0 rgba(255,255,255,.66)` |
| 描边 | `0.5px` 内描边 |

**预算**：同屏大面积 `backdrop-filter` ≤ 3 处（侧栏 / 顶栏 / 一张 hero 卡片）。底部 Sheet 打开时，`body.sheet-open` 会临时关闭卡片玻璃，保持总数 ≤ 3。
表格单元格只用透明填充，**禁止**加模糊，避免滚动掉帧。

## 6. 控件

- 按钮：胶囊圆角（999px），主色实底 + 内高光，按压 `scale(.955)` + 透明度 0.9；次要按钮用 `--fill-3`；
- 分段控件：`--fill-3` 底 + 2px padding，选中项白底 + 主色文字 + 轻阴影；
- 输入框：14px 圆角，`--card-2` 底，聚焦时白底 + 主色亮部描边；
- 表格：表头 10.5px 大写字距 0.06em，行分隔 0.5px `--fill-2`，数字右对齐；
- 环形进度：SVG，轨道 `--fill-2`，进度主色，圆头端点，`stroke-dasharray` 过渡 0.9s。

## 7. 动效曲线

| 场景 | 曲线 |
|---|---|
| 导航 lens | `cubic-bezier(.32,.72,0,1)` 0.28s |
| 按压回弹 | `cubic-bezier(.34,1.56,.64,1)` |
| Sheet 升起 | `cubic-bezier(.22,1.2,.36,1)` 0.46s |
| 抽屉滑出 | 同 Sheet |

Sheet 支持下拉拖拽关闭：拖拽阈值 90px，拖拽中禁用过渡，松手未过阈值回弹（清除内联 transform，避免残留位移）。

## 8. 降级策略（必须完整实现）

```css
/* 1. 不支持 backdrop-filter */
@supports not ((backdrop-filter:blur(1px)) or (-webkit-backdrop-filter:blur(1px))){ … 退化为不透明白色 … }

/* 2. 降低透明度偏好 */
@media (prefers-reduced-transparency: reduce){ … 关闭玻璃与背景光斑 … }

/* 3. 降低动效偏好 */
@media (prefers-reduced-motion: reduce){ … 关闭全部位移/弹簧动画 … }
```

## 10. 验收自检（逐项）

- [x] 主色唯一性：`#276B56` 只用于强调、选中态、主按钮、图表主线；`#4E9C80` 只用于渐变亮部与聚焦描边
- [x] 全部描边 `0.5px`，无 `1px` 硬边（`grep` 无 `1px solid`）
- [x] 圆角规范：卡片 24 / 弹层 30 / 控件 14 / 按钮胶囊
- [x] 玻璃数量：同屏 ≤ 3（含 Sheet 打开时的自动降级）
- [x] 降级兼容：`@supports not` + 两个媒体查询三段齐全
- [x] 弹簧动效：lens / 按压 / Sheet 三条曲线与文档一致
- [x] 按压反馈：导航项、按钮、触发按钮均有 scale + opacity
- [x] 移动端抽屉：滑出、遮罩、内容缩放变暗、关闭复位
- [x] 数字统一 tabular-nums
- [x] 无深色模式；无外部字体/图片/CDN 请求

## 11. 已知取舍

- 主内容不设最大宽度（2026-11-21 修订：去掉 720px 上限，宽屏右侧不再留大片空白）；
  超宽表仍用横向滚动容器兜底；
- 玻璃质感依赖 `backdrop-filter`，在部分低端安卓 WebView 上会退化——降级后是可读的纯白界面，不影响功能；
- 侧栏固定宽度 240px，未做折叠迷你态（规范未要求）。

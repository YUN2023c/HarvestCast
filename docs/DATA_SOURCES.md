# 数据源、授权与风险

> 一句话：**代码协议与数据授权是两件事。** 一个 MIT 库抓来的数据，不等于可以商用。

## 1. 三类数据

| 类别 | 用途 | 获取方式 | 授权状态 | 风险 |
|---|---|---|---|---|
| 期货行情（默认） | 价格、基差、波动 | 新浪财经期货日线，标准库直连 | 接口无正式商用授权，仅限研究与演示 | 中高：商用须另行授权 |
| 期货行情（备用） | 同上 | AKShare（可选） | 代码 MIT；上游站点条款各自独立 | 中：需逐源核验 |
| 基本面因子 | 产量/库存/进口/需求/政策/天气 | LLM 检索 + 人工复核 | 原始报告/公告版权归原方 | 高：口径差异、修订、时效 |
| 演示数据 | 跑通流程、单测 | `src/data/ingest.generate_demo()` | 本项目生成 | 低：但**禁止**用于真实决策 |

## 1.1 初始数据获取（`init`）

首次运行、或某品种缺数据时，**必须先取数再预测**：

```bash
python -m src.cli init                      # 全部品种
python -m src.cli init --variety corn       # 单品种
python -m src.cli init --force              # 强制重拉
```

行为约定：

| 情况 | 系统行为 |
|---|---|
| 本地已有 ≥ `--min-months`（默认 60）个月 | 跳过，不重复拉取 |
| 新浪通道可用 | 写入 CSV + `data/market/_meta.json`（来源、合约、首末月、抓取时间） |
| 新浪失败、AKShare 已安装 | 自动回退 AKShare，并在 meta 里记录失败原因 |
| 两条通道都失败 | **报错退出，不写任何行情文件**，提示检查网络或显式 `--allow-demo` |
| 已有 `--allow-demo` | 生成合成数据，meta 标记 `source: demo` |
| 真实行情落地且存在合成因子 | 合成因子被**改名隔离**为 `*.demo-<时间戳>.bak`，不删除 |

## 2. 行情接入口径

- 接口：`ak.futures_zh_daily_sina(symbol="C0")` 等，符号映射见 `src/data/ingest.py::AKSHARE_SYMBOL`；
- 聚合：日线 → 月末值（`monthly_agg: last`），成交/持仓求和；
- 主力连续**未做换月复权**。真实研究应做后复权或价差调整，否则换月跳空会被误判为行情异动（去噪层可能把跳空当异常值处理，日志会记录 `outlier-fixed`）；
- 远月价：演示数据由持有成本 + 季节预期生成；真实场景应取对应收获月合约收盘。

## 3. 基本面因子的来源要求

每条因子记录必须带：

| 字段 | 要求 | 不满足的后果 |
|---|---|---|
| `value` | 数值或 `null` | `null` 直接不入库 |
| `unit` | 与数值一致，可被 `clean.normalize_unit` 识别 | 未知单位按原值使用并告警 |
| `period` | `YYYY-MM` / `YYYY-Qn` / `YYYY` | 无法解析则丢弃 |
| `as_of_date` | 实际**发布日期**，不得晚于信息截止日 | 越界直接拒收 |
| `direction` | `bullish` / `bearish` / `neutral` | 枚举外拒收 |
| `confidence` | 0–1，低于阈值（默认 0.55）不入训练集 | 记录被剔除并计入质量报告 |
| `source_url` | 有效链接；`N/A` 视为无来源 | 无来源不入训练集 |
| `evidence_quote` | 原文摘录，不得改写 | 含"目标价/预计涨到"等表述直接拒收 |

## 4. 三个已知的数据质量陷阱

1. **口径不一致**：农业农村部"万吨"、USDA"百万蒲式耳"、行业协会"万吨/年"。系统只做单位换算，不做口径推断——冲突时保留最新一条并在 `notes` 说明。
2. **修订与回溯**：月度供需报告会修订上月数字。系统按 `(factor_id, period)` 去重保留 `as_of` 最新者，因此**不能用未来的修订值回填历史**（回测会失真）。若要严格复现，应按发布日快照存档。
3. **发布滞后**：统计口径的"当月数据"通常在次月才发布。可见性规则取 `max(period 月末, as_of 发布日)`，天然滞后 1 期以上。

## 5. 商用前的检查清单

- [ ] 行情源：拿到书面授权或使用交易所公开许可数据；
- [ ] 报告源：只引用公开摘要 + 链接，不批量复制原文；
- [ ] LLM 服务：确认供应商的数据使用条款（是否用于训练）；
- [ ] 第三方代码：核对 `THIRD_PARTY_NOTICES.md`，确认无 GPL/LGPL/AGPL；
- [ ] 对外发布：保留免责声明，不承诺收益、不使用"保证/稳赚"类表述；
- [ ] 个人信息：本项目不采集任何个人信息。
